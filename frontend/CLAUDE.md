@AGENTS.md

Design constraints — avoid generic AI-generated patterns:

Color & background: no warm cream (#F4F1EA-ish) + terracotta/clay combo, no 
near-black + single acid-green/vermilion accent, no decorative purple-to-blue 
gradients, no identical soft grey box-shadow under everything.

Layout: don't default to centered-hero → 3-4 feature cards → testimonials → 
pricing → CTA unless that's actually right for this content. Don't chop 
everything into identical rounded cards with one border-radius used 
everywhere regardless of hierarchy. Don't apply a broadsheet/hairline-rule 
editorial layout unless this is actually editorial content.

Typography: don't default to Inter or another "safe" font without reason. 
Don't bold/italicize/color a single word in a headline for emphasis. No 
tracked-out ALL CAPS eyebrow labels above every heading. No monospace font 
used decoratively when nothing is actually data.

Chrome: no middle-dot separated meta strings (A · B · C). No arrow (→) 
appended to every link/button. No numbered markers (01/02/03) unless the 
content is genuinely a sequence. No generic "trusted by" logo strips or 
stock photography.

Motion: no fade-and-slide-up entrance on every section on scroll, no hover 
lift+shadow on every card. If you use motion, make it one deliberate moment, 
not scattered effects.

Copy: no generic CTAs ("Get Started"/"Learn More"), no checkmark lists of 
vague benefits, no headline that could apply to any product in this 
category, no vague superlatives ("revolutionary," "seamless," "next-gen").

Icons: don't reach for the same default icon set (Lucide/Feather) at 
uniform weight used purely as decoration.

Before writing code: propose 2-3 distinct visual directions (palette, 
type, layout) grounded in the actual subject matter and workflow above, 
and check each one against this list — if a choice would show up in a 
completely different brief too, it's a default, not a decision. Revise 
before building.
